## Local Setup
### Prerequisites
Python 3.10+ installed
pip available
### Steps
Clone the repository:
```bash
git clone https://github.com/Khushisgh01/AI-RollCall.git
cd AI-RollCall
```
Create and activate a virtual environment:
```bash
python -m venv venv
```
On Windows:
```bash
venv\Scripts\activate
```
On macOS/Linux:
```bash
source venv/bin/activate
```
Install dependencies
```bash
pip install -r requirements.txt
```
Run the app:
```bash
streamlit run app.py
```
If your main file has a different name, replace app.py with the correct entry file.
